# צנרת ה-PDF

---

## 1. למה עברית מרונדרת כתמונה

הפונטים המובנים של `pdf-lib` תומכים ב-WinAnsi בלבד — אין בהם עברית.

לכן **כל** מחרוזת (עברית, ולשם עקביות גם לטינית) מצוירת ל-`<canvas>`
בהגדלה פי 3 עם `ctx.direction = 'rtl'`, ומוטבעת כ-PNG שקוף.

### הניב המשותף

הטכניקה חוזרת ב-5 קבצים בווריאציות (`contractOverlay.js`, `contractPdf.js`,
`filledContract.js`, `placementCertificate.js`, `formPdf.js`):

```js
await ensureFont()          // ממתין ל-document.fonts.load עבור Heebo
lineImage(text, opts)       // → { bytes, width, height }
valueImage(text, opts)
// base64 → Uint8Array → page.drawImage()
```

⚠️ בלי `ensureFont()` הקנבס מצייר בפונט ברירת מחדל והפלט נראה שונה בין דפדפנים.

## 2. שבעה מחוללים — ומתי כל אחד

| מחולל | קובץ | שיטה |
|---|---|---|
| **חוזה מאפס** | `src/tik/contractPdf.js` | בונה A4 בפריסת זרימה, גלישת מילים ו-`need()` לשבירת עמוד |
| **תעודת השמה** | `src/tik/placementCertificate.js` | תעודה דו-לשונית |
| **חבילת ההשמה** | `src/tik/filledContract.js` | מטביע על ה-PDF הרשמי (§3) |
| **טפסים מובנים** | `src/lib/formPdf.js` | pdf-lib + קנבס, כמו השאר |
| **טופס ב' ביקור בית** | `src/lib/homeVisitPdf.js` | שחזור נאמן של הטופס הממשלתי |
| **טופס טרום השמה 476** | `src/lib/preplacementPdf.js` | שחזור נאמן, ארבעה עמודים |
| **מציג החתימה** | `src/lib/pdfUtils.js` | pdf.js לרינדור + pdf-lib ליצירת החתום |

`src/lib/htmlPdf.js` אינו מחולל בפני עצמו — הוא המנוע (html2canvas/jsPDF)
ששני מרנדרי הטפסים הסטטוטוריים משתמשים בו. `formPdf.js` **אינו** קורא לו.

⚠️ כיוון התלות הפוך ממה שנראה: **`prebuiltForms.js` מייבא את שני המרנדרים**,
לא להפך. ההגדרות
הטפסים הועתקו **נאמנה ממסמכי Word שהלקוח סיפק**, וה-**מזהי השדות חייבים
להישאר יציבים** כי שני המרנדרים מפנים אליהם. אף שדה אינו חובה: עו״ס רשאי/ת
להגיש טופס חלקי.

### `placementCertificate.js` מחזיק את בלוק `AGENCY`

שם החברה בעברית ובאנגלית, ח.פ, מספר רישיון, כתובת, טלפון, מורשה חתימה, ומספר
נציב תלונות.

השם ומספר הרישיון משוכפלים ב-`manot.js` (`MANOT.company` / `MANOT.corpId`),
וה-ח.פ מופיע גם ב-`public/privacy.html`. **הכתובת, הטלפון, מורשה החתימה ומספר
נציב התלונות קיימים רק כאן.**

### `htmlPdf.js` — הטריק עם הפונטים

מנתק זמנית את תגי `<link>` של Google Fonts לפני הצילום, כדי ש-html2canvas לא
ייתקע בניסיון למשוך אותם מחדש.

### `pdfUtils.js` — שלוש החלטות

1. **עובד pdf.js מקומי** — לא CDN
2. **תקרת רסטר 2200px** לעמוד — טאבים בנייד קורסים מעבר לזה
3. **`isEvalSupported: false`** — הגנה מפני PDF זדוני

⚠️ pdf.js **מנתק (detaches)** את ה-ArrayBuffer שמועבר לו. שימוש חוזר באותו buffer
ייכשל.

## 3. חבילת ההשמה — 69 קואורדינטות מכוילות ביד

`src/tik/filledContract.js` · הנכס: `src/tik/assets/contract-template.pdf` (8.1MiB, 26 עמודים)

הקוד מטביע נתונים על החבילה הרשמית של עוגן **כדי שאף מילה משפטית מאושרת לא
תוקלד מחדש**.

**הקובץ הזה הוא כיול טהור ובלתי ניתן לשחזור.**

### מבנה

```js
add(page, x, y, value, { dir, align, size })
```

69 קריאות `add()` ישירות, בנקודות PDF (ראשית בפינה שמאלית-תחתונה), עמוד אחר עמוד, כל אחת
עם הערה שמציינת ליד איזו תווית היא יושבת.

| קבוע | ערך | תפקיד |
|---|---|---|
| `LIFT` | `4` | מרים ערכים לשורת התווית במקום מתחתיה |

⚠️ מספרי העמודים כאן הם **אנושיים (1-מבוסס)**; במקור האינדקסים
**0-מבוססים** — `page: 2` הוא עמוד 3.

### `WHITEOUT`

שני מלבנים בעמוד 3 שבהם **שם ות״ז של לקוח קודם מודפסים בתוך התבנית עצמה**.
חייבים להיצבע בלבן לפני ההטבעה.

### עמוד 10 נבנה מחדש

עמוד ה-Job Order בתבנית לא היה שמיש. הוא נבנה מאפס כקנבס מלא — כולל שמונה
סעיפי הצהרה באנגלית מילה במילה ומספר נציב התלונות.

### `toLatin()`

תעתיק עברית→לטינית אות-אות, עם כלל "ה' סופית שותקת", לטפסים ממשלתיים
באנגלית בלבד. בנוסף — טבלת לאום בעברית לצד הדו-לשוני.

### 🔑 חוק עסקי חבוי

```js
salary = round(baseSalary + weeklyAllowance * 4)
```

שכר החוזה = ברוטו חודשי + דמי כיס שבועיים × 4. דמי הכיס חייבים להיכלל בחוזה
על פי חוק. (6500 + 100×4 = 6900)

הקבוע `hoursDay = '24'` — מטפלים במתכונת "חי בבית".

## 4. גאומטריית מיקום השדות

**כל** מיקום שדה בכל המערכת משתמש באחוזי עמוד עם ראשית בפינה שמאלית-**עליונה**:

```js
{ pageIndex, xPct, yPct, wPct, hPct, align }
```

`buildOverlayPdf()` ב-`src/tik/contractOverlay.js` ממיר לראשית התחתונה של pdf-lib:

```js
y = pageHeight - yPct * pageHeight - boxHeight
```

## 5. שתי מערכות תבניות

### תבניות PDF — `contractTemplates.js`

1. העלאת PDF
2. מיקום שדות קשורים עליו, כמו שדות חתימה
3. נשמר כ-base64 בתוך שורת `kind: 'config'` (עם `data.configType === 'contract_template'`)
4. מילוי לכל תיק
5. `sendTemplateToSigning()` — הופך מיקומים עם `fieldKey === 'signature'` לשדות
   חתימה אמיתיים בבקשת החתימה

### תבניות DOCX — `contractMerge.js`

החלפת `{{placeholder}}`, עם המורכבות שחייבים להתמודד איתה: **טקסט מפוצל בין
`<w:t>` runs**. הפתרון — הרכבה מחדש פסקה-פסקה, כתיבת התוצאה ל-run הראשון
וריקון השאר, כדי שפסקאות שלא נגענו בהן ישמרו על עיצוב מדויק.

אוצר ה-placeholders (`WORKER_KEYS`, `PATIENT_KEYS`, `today`, `companyName`)
ומפת התוויות העברית `CONTRACT_FIELD_LABELS` קיימים **רק בקובץ הזה**.

## 6. גשר החתימה

`src/tik/signingBridge.js`

מעביר חוזה ממערכת המשרד לאפליקציית החתימה דרך `sign_requests` והדלי
`documents` המשותפים.

### גאומטריה מובנית

חמישה מיקומי חתימה מקודדים בעמודים **25, 26 ו-10** של חבילת 26 העמודים:

- חותם 0 = מעסיק
- חותם 1 = מטפל/ת

ניתן לדריסה דרך `placementFields` בהגדרות המשרד (`officeConfig.js`).

### SMS

`sendSigningSms()` קורא ל-Edge Function `send-sms` בשיטת fire-and-forget
ו**לעולם לא זורק** — כך שהגדרת SMS חסרה לא יכולה לשבור חתימה.

## 7. פיצול המסמך החתום — `downloadGroups` / `pageCuts`

תת-מערכת שמשפיעה גם על המשרד וגם על אפליקציית החתימה.

`downloadGroups` הוא **מחרוזת טווחים** בסגנון `"1-3 ; 4 ; 5-7"`; `pageCuts`
הם אינדקסי חיתוך מבוססי-0. השרשרת:

1. `SplitPicker.jsx` — בורר חיתוכים ויזואלי (מסרב לדרוס מפרט לא-רציף ישן)
2. נשמר **בתוך בלוב ה-`signers`** על בקשת החתימה
3. בסיום, `SignerView` מפצל את ה-PDF החתום ומעלה כל חלק ל-
   `signed/<id>-part<n>.pdf` — כדי שממסר הדוא״ל יצרף חלקים במקום קובץ אחד.
   נפילה לאחור לקובץ המלא
4. `downloadSigned()` מנתח מחדש את אותו מפרט
5. בצד המשרד, `SignFields.jsx` כותב את אותם שני מפתחות דרך
   `officeConfig.saveSignSetup()`

הפרימיטיבים — `parseGroups`, `splitByGroups`, `downloadByGroups` — ב-
`src/lib/exporters.js`.
